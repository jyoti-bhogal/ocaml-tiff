TIFF

Tiff is a library for working with TIFF (Tagged Image File Format) images in OCaml.

It provides functionality for reading and writing TIFF images and accessing image metadata.

Library tiff

The library provides APIs for working with TIFF images and their associated metadata.

  • Tiff — Main interface for working with TIFF files.
  • Tiff.Ifd — Access TIFF Image File Directory (IFD) metadata.

File access

The file access types describe how TIFF data is read from and written to files.

  • Tiff.File.ro — Read-only file access.
  • Tiff.File.wo — Write-only file access.
